## ✨ Features

- 🎨 **Modern & Minimalist Design**: Clean UI/UX focused on content readability and aesthetic appeal, built with **Tailwind CSS**.
- ⚡ **Lightning Fast Performance**: Powered by **React 18** and **Vite** for instantaneous loading and seamless navigation.
- 🪄 **Smooth Animations**: Engaging micro-interactions and scroll animations powered by **Framer Motion**.
- 📱 **Fully Responsive**: Flawless experience across desktops, tablets, and smartphones.
- ✉️ **Functional Contact Form**: Direct messaging capabilities integrated with **EmailJS**.
- 🔤 **Dynamic Typing Effects**: Eye-catching introductory text using **Typed.js**.
- 🔗 **Interactive Project Showcase**: Dedicated sections to highlight featured repositories, case studies, and live demos.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine.

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vanapallijaswanth2005/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   - Create a `.env.local` file in the root directory.
   - Add your EmailJS configuration keys (if you want the contact form to work):
     ```env
     VITE_EMAILJS_SERVICE_ID=your_service_id
     VITE_EMAILJS_TEMPLATE_ID=your_template_id
     VITE_EMAILJS_PUBLIC_KEY=your_public_key
     ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   *The application will be available at `http://localhost:5173`.*
